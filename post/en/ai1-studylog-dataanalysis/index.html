Artificial Intelligence - Data Analysis and Decision-Making #

This part is divided into four layers:

  • Data collection
  • Data cleaning
  • Data analysis
  • Decision-making

Data Collection #

Data collection is a critical step in AI: it is the source of input used to train models.

As a refresher on the basics, data collection is simply sampling the target, and we need scientific methods to make the sample close to the target.

Sampling methods generally fall into three kinds:

  1. Simple random sampling
  2. Systematic sampling
  3. Stratified sampling

Simple random sampling is the easiest to understand: a random number generator draws samples at random from the target space. Systematic sampling usually emphasizes some kind of ordering. However, the real world cannot always be represented in order, so stratified sampling can be used instead. It first divides the target into categories, and within each category other sampling methods such as systematic or simple random sampling can be applied. This kind of sampling often has more reference value for the target.

Although there are three sampling methods, there are many channels for sampling. Common ones include:

  • Surveys
  • Questionnaires
  • Interviews or focus groups
  • Transaction tracking
  • Online tracking
  • Social media monitoring

Data collection must be formal, legal, and ethical.

Data Cleaning #

Data cleaning makes the sample data reflect the target more accurately. Cleaning starts with defining the variables, which makes the data easier to work with.

Data Types #

Numerical data

  • Discrete data
  • Continuous data

Categorical data

  • Ordinal data
  • Nominal data

Discrete data takes the form of counts—definite integers—whereas continuous data can be measured with arbitrary precision and is represented as floating-point numbers. Ordinal data has an inherent ordering among its values, while nominal data does not.

Data Collection Guidelines #

  • Avoid bias

    Avoiding bias depends on the reliability of the data source: the data must truly reflect reality. Beyond that, the sampling method and measurement approach matter just as much.

  • Data representation

    Data is usually represented as a table, for example with columns for the recorded variable values and rows for the attributes of each sampling unit.

  • Data correction

    Data correction removes duplicate or misspelled records to maximize data validity as far as possible.

  • Data enrichment

    Data enrichment adds more attributes to each sampling unit so that more sample attributes can be collected.

  • Outliers

    Outliers are erroneous data points that appear during sampling, and they should be removed.

The most important step in data cleaning is removing outliers.

Data Analysis #

Before analyzing data, you need some basic mathematical concepts. They help you understand the distribution of the data and analyze it better.

Probability distributions usually fall into two kinds:

  • Discrete distributions, described by a probability mass function (PMF)
  • Continuous distributions, described by a probability density function (PDF)

Decision-Making #

The sections above only introduced various mathematical analysis methods and models for data analysis. For AI, the critical step is making decisions, so the samples we use must accurately represent the target—only then can correct decisions be made.

Here we use mathematical principles to simulate and verify, in order to determine the mathematical model of the sample.

Statistical Hypothesis Testing #

With the method in the previous section, the value of the free parameter can be obtained through likelihood estimation. However, we have not discussed whether the chosen mathematical model is correct, or whether it matches the actual target space.

In fact, the model we choose is often wrong, and we may need to try several models in turn before finding one that fits. This section uses statistical hypothesis testing so that our model accurately matches the target, allowing AI to make correct decisions.

Steps of Statistical Hypothesis Testing #

Statistical hypothesis testing is the process of deciding whether to accept or reject a statistical hypothesis. The general steps are:

  1. Formulate hypotheses: First, set up two hypotheses. The null hypothesis (H0) usually represents the original theory being tested. The alternative hypothesis (H1) is the new theory we want to prove.
  2. Choose a significance level: The significance level (usually denoted α) is the probability you are willing to accept of making a Type I error (rejecting a true null hypothesis). Common significance levels are 0.05 and 0.01.
  3. Choose an appropriate statistical test: Pick a test that fits your data type and goal. For example, to compare the means of two groups, you might choose a t-test.
  4. Determine the critical value or compute the p-value:
    • Critical value method: Compare the computed test statistic with the critical value. If the test statistic exceeds the critical value, reject the null hypothesis.
    • p-value method: If the p-value is less than the significance level α, reject the null hypothesis.
  5. Conclusion: If we reject the null hypothesis, we accept the alternative hypothesis and consider our new theory correct. If we fail to reject the null hypothesis, we say there is not enough evidence to support the new theory—but that does not necessarily mean the old theory is correct.
