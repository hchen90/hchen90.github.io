16:T1222,<h1 id="introduction">Introduction<a aria-hidden="true" tabindex="-1" href="#introduction"><span class="anchor-link"> #</span></a></h1>
<p>Artificial intelligence is nothing new; it has been developing for many years, and along with it came the numerical, matrix, graphics, and algorithm libraries that form the ecosystem AI needs.</p>
<p>AI has in fact matured over many years of development, but its presence in everyday life has been fairly subtle, so it rarely drew attention. This time, ChatGPT showed off its powerful language capabilities, which, combined with steadily improving AI algorithms, made it a huge hit and let people see the most accessible result of deep learning.</p>
<p>You can use ChatGPT directly <a href="https://chat.openai.com/">in the browser</a>, where you ask questions in a chat interface.</p>
<p>These answers are produced by calling the core large language model. OpenAI exposes this as an API: the web app uses it, and third parties access the LLM service through the same API. So we can call the API ourselves to get AI-powered Q&#x26;A (completions) and integrate AI into our own demo programs.</p>
<h1 id="a-first-look-at-the-api">A First Look at the API<a aria-hidden="true" tabindex="-1" href="#a-first-look-at-the-api"><span class="anchor-link"> #</span></a></h1>
<p>This post focuses on calling the API from a program; it does not cover how to access ChatGPT or register an account.</p>
<h2 id="get-an-api-key">Get an API Key<a aria-hidden="true" tabindex="-1" href="#get-an-api-key"><span class="anchor-link"> #</span></a></h2>
<p>Log in, go to the API Keys page, and click <code>Create new secret key</code> to generate a key for API authentication.</p>
<p><img src="/post/openaiapirsh/4be36f91ce93.png" alt="API Key"></p>
<h2 id="features">Features<a aria-hidden="true" tabindex="-1" href="#features"><span class="anchor-link"> #</span></a></h2>
<p>The API is made up of several parts.</p>
<h3 id="chat-completions">Chat Completions<a aria-hidden="true" tabindex="-1" href="#chat-completions"><span class="anchor-link"> #</span></a></h3>
<p>Chat completion is one of the key features. The AI behind it can quickly build up knowledge structures and has fairly accurate language understanding and responses.</p>
<p><img src="/post/openaiapirsh/57a4bd3490ec.png" alt="Official documentation"></p>
<p>The official API documentation describes each API call in some detail:</p>
<p><img src="/post/openaiapirsh/b40c146873c9.png" alt="Chat API documentation"></p>
<p>It shows the chat request format. Here is an example request I sent:</p>
<p><img src="/post/openaiapirsh/d7ffc532bab4.png" alt="Chat example"></p>
<p>The response is broadly the same as what the web version of ChatGPT returns.</p>

<p>Other parts include text completion, speech-to-text, and more. Check the official site if you're interested.</p>

<h1 id="caveats">Caveats<a aria-hidden="true" tabindex="-1" href="#caveats"><span class="anchor-link"> #</span></a></h1>
<p>Things to keep in mind:</p>
<ul>
<li>The ChatGPT website is not accessible from mainland China; you need a proxy to reach it</li>
<li>The free tier of the OpenAI API is rate-limited; once you hit the request threshold, requests get throttled</li>
<li>The paid tier of the OpenAI API does not work well with international credit cards issued in mainland China (even if payment succeeds, the account may still risk being banned)</li>
</ul>
<p>A free account is usually enough for casual use.
