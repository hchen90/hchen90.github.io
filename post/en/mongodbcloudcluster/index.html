What Is MongoDB Cloud #

At the core of MongoDB Cloud is MongoDB Atlas, a fully managed cloud database for modern applications. Atlas is the best way to run MongoDB, the leading modern database. MongoDB's document model is a faster way to innovate, bringing flexibility and ease of use to the database.

That is the official description. Next, let's look at the pricing:

As you can see, there is a free shared tier. It runs as a sandbox environment and already includes basic data storage. If you need more storage, network isolation, and so on, consider the other two tiers.

Configure the Cluster #

The configuration is fairly simple and has two main parts: under Data, trigger configuration; under Security, database user configuration and network access configuration.

Database user configuration adds users who can access the database, including setting a username and password; certificate-based authentication is also an option:
