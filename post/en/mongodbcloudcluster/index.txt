16:Teaa,<h1 id="what-is-mongodb-cloud">What Is MongoDB Cloud<a aria-hidden="true" tabindex="-1" href="#what-is-mongodb-cloud"><span class="anchor-link"> #</span></a></h1>
<p>At the core of MongoDB Cloud is <a href="https://www.mongodb.com/zh-cn/cloud/atlas">MongoDB Atlas</a>, a fully managed cloud database for modern applications. Atlas is the best way to run MongoDB, the leading modern database. <a href="https://www.mongodb.com/zh-cn/what-is-mongodb">MongoDB</a>'s document model is a faster way to innovate, bringing flexibility and ease of use to the database.</p>
<p>That is the official description. Next, let's look at the pricing:</p>
<p><img src="/post/mongodbcloudcluster/5e3ecd48dd31.png" alt="Pricing"></p>
<p>As you can see, there is a free shared tier. It runs as a sandbox environment and already includes basic data storage. If you need more storage, network isolation, and so on, consider the other two tiers.</p>
<h1 id="creating-a-db-cluster">Creating a DB Cluster<a aria-hidden="true" tabindex="-1" href="#creating-a-db-cluster"><span class="anchor-link"> #</span></a></h1>
<h2 id="log-in">Log In<a aria-hidden="true" tabindex="-1" href="#log-in"><span class="anchor-link"> #</span></a></h2>
<p>First, log in to your MongoDB Cloud account. If you don't have one, create an account, log in, and go to the Dashboard:</p>
<p><img src="/post/mongodbcloudcluster/55e80b53d456.png" alt="Dashboard"></p>
<blockquote>
<p>Note: a cluster has already been created in the screenshot above.</p>
</blockquote>
<h2 id="create-a-cluster">Create a Cluster<a aria-hidden="true" tabindex="-1" href="#create-a-cluster"><span class="anchor-link"> #</span></a></h2>
<p>From the Dashboard you can create a cluster and configure it, including the data region, the cloud provider, and other settings. <img src="/post/mongodbcloudcluster/70d232773614.png" alt="Create cluster"></p>
<p>Pick a low-latency data region based on your service needs:</p>
<p><img src="/post/mongodbcloudcluster/36823cf56cee.png" alt="Region"></p>
<p>And the cloud provider:</p>
<p><img src="/post/mongodbcloudcluster/0d5e3adf8ab3.png" alt="Provider"></p>
<p>You can also configure some additional cluster settings (for example, the database version to use):</p>
<p><img src="/post/mongodbcloudcluster/c4322124a40f.png" alt="Settings"></p>
<h2 id="configure-the-cluster">Configure the Cluster<a aria-hidden="true" tabindex="-1" href="#configure-the-cluster"><span class="anchor-link"> #</span></a></h2>
<p>The configuration is fairly simple and has two main parts: under Data, trigger configuration; under Security, database user configuration and network access configuration.</p>
<p>Database user configuration adds users who can access the database, including setting a username and password; certificate-based authentication is also an option:</p>
<p><img src="/post/mongodbcloudcluster/04695e885b07.png" alt="Add user"></p>
<p>After creating a user, we still cannot log in to the database: we also need to add our client's IP address to the allowlist:</p>
<p><img src="/post/mongodbcloudcluster/e67ad7e2dd3d.png" alt="IP allowlist"></p>
<blockquote>
<p>Note:</p>
<p>Don't forget to add your IP to the allowlist, or connections will fail.</p>
</blockquote>
