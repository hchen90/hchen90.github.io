16:T43a3,<h1 id="artificial-intelligence---machine-learning">Artificial Intelligence - Machine Learning<a aria-hidden="true" tabindex="-1" href="#artificial-intelligence---machine-learning"><span class="anchor-link"> #</span></a></h1>
<p>The foundation of artificial intelligence is machine learning. As the name suggests, it lets machines process data and learn from that data so they can make decisions on their own. Put simply, machine learning lets a machine learn and improve without being explicitly programmed for the task.</p>
<p>Machine learning falls broadly into three kinds: supervised learning, unsupervised learning, and deep learning.</p>
<h2 id="supervised-learning">Supervised Learning<a aria-hidden="true" tabindex="-1" href="#supervised-learning"><span class="anchor-link"> #</span></a></h2>
<p>Supervised learning is a machine learning approach that learns a model or function from labeled training data (that is, known inputs and outputs). The model or function can then be used to predict new, unseen data. During training, whenever the model's prediction differs from the actual result, the model is adjusted to reduce that difference. It is as if a "supervisor" were guiding the machine on how to learn.</p>
<p>Supervised learning naturally depends on training algorithms. Its defining characteristic is that it needs both inputs and outputs, with feedback on the output (and the data used in supervised learning is always labeled).</p>
<p>Common supervised learning algorithms include linear regression, logistic regression, decision trees, support vector machines (SVM), and the K-NN (nearest neighbor) algorithm.</p>
<h3 id="linear-regression">Linear Regression<a aria-hidden="true" tabindex="-1" href="#linear-regression"><span class="anchor-link"> #</span></a></h3>
<p>Linear regression is a common predictive analysis method, suitable when two or more variables have a linear relationship. In machine learning, the goal of linear regression is to find a best-fit line that minimizes the sum of the vertical distances (the errors) from all data points to that line. This process is also known as the least squares method.</p>
<p>The general form of a linear regression model is Y = aX + b, where Y is the dependent variable (the target we want to predict), X is the independent variable (the input we use to predict), and a and b are model parameters that determine the slope and intercept of the line.</p>
<p>Linear regression provides a way to quantify the relationship between independent and dependent variables, and it underpins many more complex models and techniques. It is widely used across fields including economics, biology, environmental science, and the social sciences.</p>

<h3 id="logistic-regression">Logistic Regression<a aria-hidden="true" tabindex="-1" href="#logistic-regression"><span class="anchor-link"> #</span></a></h3>
<p>Logistic regression is a statistical technique for predictive analysis used to solve binary classification problems. It uses the logistic function to map the output of a linear regression into the range between 0 and 1, which makes it a good tool for classification. The main goal of logistic regression is to find the logistic function that best describes the relationship between the input variables and the output; the function's output can be interpreted as the probability that an event occurs.</p>
<p>The general form of a logistic regression model is p = 1 / (1 + e^(-z)), where p is the predicted probability, z = aX + b, a and b are model parameters, and X is the input variable. During training we need to find the a and b that minimize the difference between the predicted probabilities and the actual class labels. This is usually done with maximum likelihood estimation or gradient descent.</p>
<p>Logistic regression is very useful for understanding the factors that influence an outcome, predicting outcomes, and building simple classification models. It is widely used in finance, healthcare, the social sciences, and many other fields.</p>
<h3 id="decision-trees">Decision Trees<a aria-hidden="true" tabindex="-1" href="#decision-trees"><span class="anchor-link"> #</span></a></h3>
<p>A decision tree is a tree-structured machine learning model for classification and regression. It splits the dataset into different subsets through a series of splitting rules, eventually forming a tree: each node represents a feature, each branch represents a possible value of that feature, and each leaf represents a classification or regression result.</p>
<p>The main advantages of decision trees are:</p>
<ol>
<li><strong>Easy to understand and interpret</strong>: The model's structure is intuitive, easy to explain, and well suited to visualization.</li>
<li><strong>Little data preprocessing</strong>: Decision trees do not need much preprocessing, such as normalization or filling in missing values.</li>
<li><strong>Handles multiple data types</strong>: Decision trees can handle both numerical and categorical data, which makes them quite flexible.</li>
</ol>
<p>Building a decision tree usually involves these steps:</p>
<ol>
<li><strong>Choose the best feature</strong>: Select the best feature to split on according to some metric (such as information gain or the Gini index).</li>
<li><strong>Create split points</strong>: Create split points based on the chosen feature, dividing the data into several subsets.</li>
<li><strong>Split recursively</strong>: Repeat steps 1 and 2 recursively on each subset until a stopping condition is met (such as reaching the maximum tree depth, or the number of samples in a leaf falling below a threshold).</li>
</ol>
<p>The disadvantages of decision trees are:</p>
<ol>
<li><strong>Prone to overfitting</strong>: Decision trees easily overfit the training data, especially when the tree is deep. Pruning or setting a maximum depth can mitigate this.</li>
<li><strong>Sensitive to noise</strong>: Decision trees are fairly sensitive to noisy data, which can make the tree unstable.</li>
</ol>
<p>Decision trees perform well in many practical applications, such as credit scoring, medical diagnosis, and market analysis. They can also be combined with other models, as in ensemble methods like random forests and gradient boosted trees.</p>

<h3 id="k-nn-nearest-neighbor-algorithm">K-NN (Nearest Neighbor) Algorithm<a aria-hidden="true" tabindex="-1" href="#k-nn-nearest-neighbor-algorithm"><span class="anchor-link"> #</span></a></h3>
<p>The K-NN algorithm, short for K-Nearest Neighbors, is a simple and intuitive method for classification and regression. Its basic idea is: given a sample to classify, find the K samples in the training set closest to it, then decide the sample's class from those K samples by voting or averaging.</p>
<p>The steps of K-NN are:</p>
<ol>
<li><strong>Choose K</strong>: Pick a positive integer K, the number of nearest neighbors to consider.</li>
<li><strong>Compute distances</strong>: For the sample to classify, compute its distance to every sample in the training set. Common distance metrics include Euclidean distance and Manhattan distance.</li>
<li><strong>Select the K nearest neighbors</strong>: Based on the computed distances, pick the K closest samples from the training set.</li>
<li><strong>Vote or average</strong>: Let the K nearest neighbors vote and assign the most frequent class to the sample; for regression, use the average of the K nearest neighbors as the prediction.</li>
</ol>
<p>Advantages of K-NN:</p>
<ul>
<li><strong>Simple to implement</strong>: K-NN has no explicit training phase; it classifies and regresses directly based on distance.</li>
<li><strong>Non-parametric model</strong>: K-NN does not need to learn model parameters, which suits small training sets.</li>
</ul>
<p>Disadvantages of K-NN:</p>
<ul>
<li><strong>Computationally expensive</strong>: For every sample to classify, distances to all training samples must be computed, which is costly.</li>
<li><strong>Poor on high-dimensional data</strong>: In high-dimensional spaces, distances between data points become hard to measure meaningfully, and K-NN performs poorly.</li>
<li><strong>Sensitive to noise</strong>: K-NN is fairly sensitive to noise and outliers, which affects classification results.</li>
</ul>
<p>Even so, K-NN still performs well in many practical applications, especially classification problems—for example, handwritten digit recognition, image classification, and text classification.</p>
<h2 id="unsupervised-learning">Unsupervised Learning<a aria-hidden="true" tabindex="-1" href="#unsupervised-learning"><span class="anchor-link"> #</span></a></h2>
<p>Unsupervised learning is a machine learning approach that does not use labeled data during training. It lets the algorithm learn from the input data by itself and identify patterns and structure within it. The goal is usually to uncover patterns or relationships hidden in the data, such as through clustering or dimensionality reduction. Because there is no predefined target or output variable, unsupervised learning is often used for exploratory analysis to help researchers identify unknown patterns or relationships.</p>
<p>Its typical characteristic is that there is input data but no output data (unsupervised learning uses unlabeled data).</p>
<p>In unsupervised learning, the input data is unstructured. To handle this unlabeled, unstructured data, it needs to be clustered and reduced in dimension so that useful information can be extracted.</p>
<p>Common unsupervised algorithms include clustering algorithms (K-means) and principal component analysis (PCA).</p>
<h3 id="k-means-algorithm">K-means Algorithm<a aria-hidden="true" tabindex="-1" href="#k-means-algorithm"><span class="anchor-link"> #</span></a></h3>
<p>K-means is a common unsupervised learning algorithm used to partition a dataset into K clusters. It works by iterative optimization, assigning data points to the nearest cluster center, so that similarity within each cluster is maximized and similarity between clusters is minimized. The steps are:</p>
<ol>
<li>Randomly choose K initial cluster centers.</li>
<li>Assign each data point to the nearest cluster center.</li>
<li>Compute the new center of each cluster, i.e., the mean of all data points in the cluster.</li>
<li>Repeat steps 2 and 3 until the cluster centers no longer change significantly or a preset number of iterations is reached.</li>
</ol>
<p>K-means is simple and efficient and works for large datasets, but K must be specified in advance, and the algorithm is fairly sensitive to the choice of initial cluster centers.</p>
<h3 id="principal-component-analysis-pca">Principal Component Analysis (PCA)<a aria-hidden="true" tabindex="-1" href="#principal-component-analysis-pca"><span class="anchor-link"> #</span></a></h3>
<p>Principal component analysis (PCA) is a statistical method that simplifies a dataset through dimensionality reduction. Its purpose is to find the lower-dimensional space that best represents the distribution of the original data. PCA works by creating a new coordinate system and remapping the original data onto it. The basis of the new coordinate system consists of the principal components of the original data (the directions of greatest variance). In the new system, most of the information is compressed into the first principal component, the next largest share into the second, and so on. By keeping the first few principal components and discarding the rest, we reduce the data's dimensionality. PCA is widely used in image compression, data visualization, noise filtering, feature extraction, and data preprocessing.</p>

At the core of deep learning are neural networks, especially deep neural networks, which contain multiple hidden layers, each performing a specific kind of data processing.
