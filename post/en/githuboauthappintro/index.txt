16:Tc0d,<p>GitHub offers two kinds of apps: regular Apps (often used for automation bots) and OAuth Apps that act on behalf of a signed-in user. With an OAuth App you can call GitHub APIs that the user authorized—profile data, repository changes, account settings, and more.</p>
<h1 id="what-is-oauth-2">What is OAuth 2<a aria-hidden="true" tabindex="-1" href="#what-is-oauth-2"><span class="anchor-link"> #</span></a></h1>
<p>OAuth (Open Authorization) is an open standard that lets users grant a third-party app access to data stored at another provider <strong>without</strong> sharing their password. OAuth 2.0 is the successor to OAuth 1.0 and is not backward compatible.</p>
<h1 id="github-oauth-apps">GitHub OAuth Apps<a aria-hidden="true" tabindex="-1" href="#github-oauth-apps"><span class="anchor-link"> #</span></a></h1>
<p>OAuth 2 lets an external app read private GitHub account data without collecting the user’s password. The OAuth App uses GitHub as the identity provider. Tokens are scoped and can be revoked at any time, which is safer than handing out a password.</p>
<p>An OAuth App behaves like an authenticated user and is usually hosted on a site that receives the OAuth redirect with callback parameters.</p>
<p>See the <a href="https://docs.github.com/en/developers/apps/getting-started-with-apps/about-apps">GitHub docs on apps</a> for more detail.</p>
<h1 id="creating-an-oauth-app-on-github">Creating an OAuth App on GitHub<a aria-hidden="true" tabindex="-1" href="#creating-an-oauth-app-on-github"><span class="anchor-link"> #</span></a></h1>
<p>Sign in to GitHub, open <strong>Settings → Developer settings</strong>, then create a <strong>GitHub OAuth App</strong> (not a GitHub App).</p>
<h2 id="developer-settings">Developer settings<a aria-hidden="true" tabindex="-1" href="#developer-settings"><span class="anchor-link"> #</span></a></h2>
<p>In the left sidebar under personal settings, open <strong>Developer settings</strong>.</p>
<p><img src="/post/githuboauthappintro/644167c2069a.png" alt="settings"></p>
<p>Create an OAuth App named <em>blogchat</em>:</p>
<p><img src="/post/githuboauthappintro/4a33dc6f63c6.png" alt="oa_app"></p>
<p>After creation you get a <strong>Client ID</strong>, <strong>Client secrets</strong>, and can change the logo:</p>
<p><img src="/post/githuboauthappintro/862e69104174.png" alt="oa_app_cb1"></p>
<p>Two important fields are the <strong>Homepage URL</strong> and the <strong>Authorization callback URL</strong>:</p>
<p><img src="/post/githuboauthappintro/f99c9c4d679a.png" alt="oa_app_cb2"></p>
<blockquote>
<p>The callback URL receives a <code>code</code> used later to exchange for an <code>access_token</code>.</p>
