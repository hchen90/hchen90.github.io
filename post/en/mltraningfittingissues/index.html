Fitting Problems in Machine Learning Model Training

September 15, 2024
AIMachine Learning

What Are Fitting Problems #

Fitting problems boil down to how well a model learns the patterns in the data. A model that learns well is said to have a good fit; one that learns poorly falls into one of two categories: overfitting or underfitting.

Fitting means approximating the relationships in the data with a model function, and the degree of fit reflects how closely the model function matches the actual data.

Overfitting #

Overfitting means the model performs very well on the training data but poorly on test data. The usual cause is fitting the training set too closely, to the point of learning its noise, which leads to large errors when generalizing to new data.

Underfitting #

Underfitting means the model performs poorly on both the training and test sets, because the fit is too weak to capture the patterns in the data.

What the Phi coefficient means

The Phi coefficient measures the correlation between predictions and actual outcomes: +1 means perfect prediction, 0 means completely random, and -1 means completely inverted. It generally ranges from -1 to 1, and the closer to 1, the better.

Fixing Underfitting #

There are several common ways to address underfitting. The first is to add or remove features (add features to datasets with too few, remove them from datasets with too many), adjusting the feature count so the model can learn the patterns during training. The second is to try a different model, because different models suit different datasets. For example, if the data has simple linear relationships, linear models such as linear or logistic regression fit better; if there are many features with non-linear relationships, a decision tree is more appropriate. The third is to increase the sample size if there are too few samples, which also helps the model learn from the dataset.

Summary #

In machine learning, both overfitting and underfitting can be spotted by training the model and evaluating the results. Overfitting is usually a labeling problem in the dataset and can be fixed with appropriate corrections. Underfitting needs closer observation to decide whether the model choice is wrong, the features are insufficient, or the sample space is too small.
